# Hardware materials

This directory contains the public hardware materials for the STM32 smart cleaning car.

- `cleaning-car-schematic.pdf` is the read-only schematic export.
- `cleaning-car-schematic.epro2` is the editable schematic project source.

The schematic is for the prototype described in the repository. Pin assignments, motor direction, encoder polarity, battery ADC scaling, wheel parameters, and CAN wiring should be checked again before reusing the design on another chassis.
